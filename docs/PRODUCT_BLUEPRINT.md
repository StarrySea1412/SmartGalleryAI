# 产品构思

## 一句话定位

SmartGalleryAI 是一个本地优先的智能图库，把散落在电脑、NAS、截图目录和备份盘里的图片整理成可搜索的视觉知识库。

## 目标用户

- 图片资料很多但整理成本高的个人用户。
- 设计师、摄影师、内容创作者。
- 经常保存网页截图、票据、文档图片的知识工作者。
- 希望自托管、重视隐私的开源用户。

## 核心场景

### 1. 截图资料库

用户保存大量截图后，可以搜索：

- 某个报错信息。
- 某段中文文字。
- 带有某个 UI 页面或图表的截图。

### 2. 个人照片库

用户可以搜索：

- 有海边、雪山、夜景的照片。
- 某个时间段拍摄的图片。
- 和当前图片相似的照片。

### 3. 设计素材库

用户可以搜索：

- 蓝色按钮界面。
- 极简风格海报。
- 包含 logo、包装、字体样式的参考图。

### 4. 票据与文档图片

用户可以搜索：

- 包含金额、公司名、日期的票据。
- 某个证件、合同扫描件、白板照片。

## MVP 功能

1. 导入图片目录。
2. 保存图片元数据。
3. 生成缩略图。
4. OCR 文本识别。
5. 图片标签和描述。
6. 关键词搜索。
7. 语义搜索。
8. 图片详情页 API。

## 非目标

第一阶段不建议优先做：

- 复杂社交分享。
- 移动端原生 App。
- 云相册同步平台。
- 重型权限系统。
- 一开始就支持所有图片和视频格式。

## 差异化

SmartGalleryAI 的差异化应放在：

- 本地优先。
- AI Provider 可插拔。
- 数据可导出。
- 面向整理与搜索，而不是只做展示。
- 对中文 OCR 和中文搜索体验友好。

## 成功标准

第一版真正成功的标志不是功能多，而是用户导入 5000 张图片后，可以稳定完成：

- 找到包含特定文字的截图。
- 找到相似图片。
- 用自然语言找到大致想要的图。
- 查看每张图片为什么被搜索命中。
